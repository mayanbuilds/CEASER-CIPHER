How it works

The Caesar cipher is one of the oldest known encryption techniques, named after Julius Caesar who used it to protect military messages by shifting each letter a fixed number of positions down the alphabet.

Each letter is mapped to a number (A = 0 … Z = 25). A shift key k moves every letter forward (encrypt) or backward (decrypt), wrapping around from Z to A via modular arithmetic modulo 26.

Encrypt C[i] = (P[i] + k) mod 26
Decrypt P[i] = (C[i] − k + 26) mod 26

Implementation notes

1. Validation strategy

Invalid input is rejected with a clear error. It is never silently corrected — no trimming or auto-uppercasing unless the user enables the toggle.

2. Why + 26 in decryption

JavaScript's % can return a negative remainder. (0 − 3) % 26 = −3; adding 26 gives 23 = 'X', which is correct.

3. Edge cases k = 0 and k = 25

k = 0 leaves text unchanged. k = 25 shifts back by 1 since 25 ≡ −1 (mod 26). Both are covered by the test suite.
